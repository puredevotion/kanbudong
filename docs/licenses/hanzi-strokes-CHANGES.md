# Changes to Make Me a Hanzi's stroke graphics

Per `ARPHICPL.TXT` §2(a): a record of what was done to the data.

- **Source**: `graphics.txt` from
  [`skishore/makemeahanzi`](https://github.com/skishore/makemeahanzi)
  (commit tracked by whatever `docs/research/corpus/fetch.sh` last pulled),
  itself derived from Arphic Technology's `AR PL` font outlines per that
  repo's own `APL/` licensing.
- **Subsetted**: only the `strokes`/`medians` entries for characters that
  actually appear in `packages/engine/src/content/**/*.ts` are kept — not
  the full ~9,000-character file. See `docs/LICENSING.md`'s table row for
  why this is a subset, not the whole dataset.
- **Reformatted**: each kept entry is stripped of every field but
  `strokes` and `medians` (`character`, `radStrokes`, etc. dropped) and
  re-keyed by the character itself, matching the `CharacterJson` shape
  `hanzi-writer` (MIT) expects as a per-character loader response.
- **Generated by**: `scripts/build-strokes.mjs`, run as `pnpm strokes`
  (also wired into `pnpm build`). Regenerate after running
  `docs/research/corpus/fetch.sh` to refresh the gitignored scratch copy
  of `graphics.txt` — the script fetches nothing itself.
- **Output**: `apps/pwa/public/strokes/data.json`, shipped alongside this
  file and `ARPHICPL.TXT` per the Arphic license's redistribution terms.
